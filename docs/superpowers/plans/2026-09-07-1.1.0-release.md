# 1.1.0 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish the verified Apple Silicon-only release candidate as GitHub Release `v1.1.0`.

**Architecture:** Current release metadata is changed consistently to 1.1.0 while historical planning documents retain their 1.2.0 context. The existing tag-triggered GitHub Actions workflow remains unchanged: a pushed `v1.1.0` tag must match `CFBundleShortVersionString`, create the release artifacts, and publish them through GitHub Releases.

**Tech Stack:** Swift 5.9, Swift Package Manager, bash, Git, GitHub Actions, GitHub CLI.

## Global Constraints

- Apple Silicon (`arm64`) is the only supported architecture.
- Minimum supported macOS version is 13.0.
- The current release version is `1.1.0` and the release tag is `v1.1.0`.
- The release tag must exactly match `CFBundleShortVersionString`.
- Do not recreate, edit, or delete the existing `v1.0.0` release.
- Preserve historical `1.2.0` references in `docs/superpowers/` planning records.

### Task 3: Create and Verify GitHub Release v1.1.0

**Files:**

**Interfaces:**
- Consumes: green `main` CI and `Resources/Info.plist` version `1.1.0`.


Expected: The workflow concludes with `success`.

```bash

```
